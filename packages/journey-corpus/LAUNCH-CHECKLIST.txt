# Atlas seven-candidate-cohort launch checklist

Status: human review required

Candidate cohorts:

- Deploy a web app: Render, Vercel, Netlify, and Railway.
- Receive a first direct model API response (current priority): OpenAI, Anthropic, Gemini Developer API, xAI API for Grok, Mistral, Cohere, DeepSeek, Perplexity, and AI21 Jamba.
- Receive a first managed inference or routed response: GroqCloud, Together AI, Fireworks AI, Cerebras Inference, Replicate, OpenRouter, Hugging Face Inference Providers, NVIDIA NIM, and Cloudflare Workers AI.
- Receive a first cloud model-platform response: Amazon Bedrock, Microsoft Foundry, Google Vertex AI, IBM watsonx.ai, OCI Generative AI, Databricks Foundation Model APIs, and Snowflake Cortex AI.
- Send a first transactional email: Resend, Postmark, Mailgun, and Twilio SendGrid.
- Complete a managed database data round trip: Neon, Supabase, CockroachDB, and MongoDB.
- Complete a first hosted-auth login: Auth0, Stytch, Descope, and FusionAuth.

These are review hypotheses from `trust/launch-cohort-candidates.json`, not certified comparison cohorts. Naming a platform does not make it eligible. Only Render currently passes every publication gate. Each remaining platform stays non-public until every applicable item below is independently completed.

Per-platform review

- Identity resolved.
- First-party source content reviewed.
- Selected route and alternative branches reviewed.
- Required field inventory reviewed.
- First-success boundary and observable result agreed.
- Starting boundary, first-success boundary, route granularity, category, and organization equivalence certified for the cohort.
- Durable direct link verified in the deployed environment.
- Server-rendered title, description, canonical URL, and Open Graph metadata verified.
- Correction path opened with the intended platform context, without submission.
- Publication decision recorded.

Current state

- Qualified cohorts: 0 of 5 required from 7 candidates.
- Routes with at least three qualified peers: 0 of 41 required.
- Render: local identity, source, route, fields, boundary, and correction artifacts complete. Production verification of this change remains.

Required pilot evidence

- At least 20 representative people complete the route-understanding flow.
- At least 5 people copy a platform share link.
- At least 3 recipients open a shared link and view a second platform.
- At least 2 useful corrections are started.
- Route-accuracy and user-value protocols in evaluation/product-validation-protocols.json pass their predeclared thresholds.

These are initial decision thresholds. Local implementation does not satisfy them.
